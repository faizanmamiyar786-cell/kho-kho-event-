# Kho Kho Championship website

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Edit event placeholders directly in `index.html` (date, venue, event duration, schedule, contact email).

No build tools are required. This is a static HTML/CSS/JavaScript starter site.

## Important before publishing
- Replace the generic sports hero image URL in `style.css` with an authentic Kho Kho photograph you have permission to use.
- Replace `organisers@example.com` in `index.html` with the event's real contact email.
- The registration form is a frontend demonstration. It saves enquiries in the visitor's browser using localStorage; it does NOT send them to the organisers or store them centrally.
- To accept real registrations, connect the form to a backend/API and database, add server-side validation, privacy information and appropriate access controls.
- The match centre/team directory are currently informational placeholders; live scores require a scoring workflow and backend.
